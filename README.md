# 🌸 Iris Flower Classification

## 🔹 Project Overview

This project focuses on classifying Iris flowers into three species — Setosa, Versicolor, and Virginica — using machine learning techniques based on flower measurements.

## 🔹 Dataset Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## 🔹 Objective

To build a machine learning model that can accurately predict the species of an Iris flower based on its features.

## 🔹 Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

## 🔹 Machine Learning Model

* Logistic Regression / Decision Tree (jo bhi tumne use kiya ho)
* Train-test split applied
* Model evaluated using accuracy score

## 🔹 Key Results

* High accuracy achieved in classification
* Petal length and width were the most important features

## 🔹 Conclusion

The Iris dataset is a simple yet powerful dataset for understanding classification problems in machine learning.
